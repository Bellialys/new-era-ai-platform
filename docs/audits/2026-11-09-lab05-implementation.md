## 3. Архітектура

Browser (Next.js/React, /saved-prompts) -> Next.js Route Handlers (Node.js) -> Supabase PostgreSQL (saved_prompts).
Ідентичність: перевірена Supabase Auth-сесія через getAuthenticatedUserId(). Гостям цей CRUD недоступний.
Оновлення сторінки: клієнтський fetch із cache: no-store; серверні маршрути dynamic=force-dynamic; після POST/PATCH/DELETE виконується revalidatePath('/saved-prompts') та повторний GET у клієнті.

### REST API

| Метод | Маршрут | Успіх | Призначення |
|---|---|---|---|
| GET | /api/saved-prompts | 200 | Список (до 50 записів), нові спочатку |
| POST | /api/saved-prompts | 201 | Створення {title,promptText} |
| GET | /api/saved-prompts/:id | 200 | Прочитати один запис |
| PATCH | /api/saved-prompts/:id | 200 | Частково оновити запис |
| DELETE | /api/saved-prompts/:id | 200 | Видалити запис |

Помилки: 400 INVALID_BODY/INVALID_JSON/VALIDATION_ERROR, 401 AUTH_REQUIRED, 403 CSRF_REJECTED, 404 NOT_FOUND, 429 RATE_LIMIT, 503 PERSISTENCE_UNAVAILABLE.

### Модель даних

public.saved_prompts: id (uuid PK), user_id (uuid FK auth.users), title (1–80), prompt_text (3–8000), created_at/updated_at (timestamptz). Індекс (user_id, updated_at DESC, id DESC). RLS активний; прямі права anon/authenticated відкликані; service_role використовують лише на сервері.

## 4. Безпека / STRIDE

- **Spoofing:** ідентичність не приймається в body, лише з перевіреної сесії Supabase.
- **Tampering / CSRF:** requireSameOriginMutation; відкидання невідомих полів; серверна валідація.
- **Repudiation:** існуюче logApiRequest без зберігання самого тексту запитів у логах.
- **Information disclosure:** owner-filter у кожній операції; незнайомі й відсутні UUID однаково отримують 404; whitelist DTO; cache no-store.
- **Denial of service:** rate-limit; обмеження полів; обмеження 50 елементів у відповіді списку.
- **Elevation of privilege:** Supabase service-role ніколи не передається браузеру; усі серверні запити вимагають власника.
- **Known residual:** у Supabase Security Advisor перед змінами було попередження Leaked Password Protection Disabled; його виправлення — окрема зміна політики Auth.
